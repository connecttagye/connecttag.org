قالب هوتسبوت مايكروتك العصري

Modern Hotspot Portal for MikroTik RouterOS

قالب احترافي حديث ومتجاوب لبوابات تسجيل الدخول لشبكات المايكروتك (Captive Portal). مصمم للهواتف المحمولة والمتصفحات، يدعم تشفير MD5/CHAP، حماية محاولات التخمين، وترجمة كاملة لرسائل أخطاء RouterOS باللغة العربية.

MikroTik RouterOS JavaScript HTML5 / CSS3 MD5 / CHAP Arabic RTL 100% Offline
  • تشفير CHAP / MD5: متوافق مع نظام مصادقة مايكروتك المشفر.
  • حماية الكوكيز (Cookie Guard): حد أقصى للمحاولات الخاطئة لمنع التخمين.
  • رسائل أخطاء عربية دقيقة: توضيح مباشر لحالات انتهاء الرصيد، انتهاء الوقت، أو الجهاز المستخدم.
  • شاشات متكاملة: تسجيل الدخول (login)، الحالة (status)، والقطع المؤقت أو النهائي.

جرّب تعديل كلمات البحث أو تصفح جميع التصنيفات المتاحة.

دليل تثبيت قالب الهوتسبوت على MikroTik
خطوات التركيب عبر Winbox:
  1. قم بتنزيل محتويات المستودع من GitHub.
  2. افتح برنامج Winbox واتصل بسيرفر أو راوتر المايكروتك الخاص بك.
  3. توجّه إلى القائمة الجانبية: Files.
  4. اسحب مجلد القالب (أو انسخ ملفاته) وضعه مباشرة داخل مجلد hotspot في الراوتر.
  5. توجّه إلى IP > Hotspot > Server Profiles وافتح البروفايل الخاص بشبكتك.
  6. في خانة HTML Directory اختر مجلد القالب.
  7. احفظ الإعدادات، واستمتع بتصميم عصري سريع ومتجاوب!
ملاحظة: القالب يعمل محلياً 100% بدون الحاجة لإنترنت خارجي لجلب الخطوط أو الأيقونات لضمان ظهوره الفوري للمستخدمين.
