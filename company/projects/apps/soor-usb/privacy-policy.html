توضح هذه السياسة التزام شركة كونكت تاق لتقنية المعلومات (Connect Tag) بحماية الخصوصية وأمن البيانات في تطبيق "سور USB" (SoorUsb) المخصص لحماية وإدارة منافذ وسائط التخزين على نظام Windows.

1. معالجة محلية 100% وعزل تام عن الإنترنت

  • يعمل تطبيق "سور USB" محلياً بالكامل داخل نظام التشغيل Windows دون أي اتصال بالإنترنت أو خوادم خارجية.
  • لا يقوم التطبيق بفحص أو قراءة أو نسخ أي ملفات مخزنة على القرص الصلب أو وسائط التخزين، بل يقتصر عمله على ضبط سياسة التشغيل والأمان لمنفذ وسائط التخزين في النظام.
  • تُحفظ كلمة المرور الإدارية مشفرة محلياً باستخدام خوارزميات التجزئة القياسية المعتمدة (SHA-256 مع Salt عشوائي).

2. عدم جمع أو مشاركة البيانات

لا يجمع التطبيق ولا يشارك أي معلومات شخصية أو بيانات جهاز أو سجلات استخدام مع شركة Connect Tag أو أي طرف ثالث.

This Privacy Policy outlines Connect Tag's privacy standards for the Soor USB endpoint storage control utility for Windows.

1. 100% Local & Offline Operation

  • Soor USB operates entirely offline on the local Windows workstation with zero internet connectivity.
  • The software does not read, index, or copy any user files on hard drives or USB drives; it exclusively governs operating system storage port states (Enabled, Read-Only, or Disabled).
  • The administrator password is protected locally using industry-standard salted SHA-256 cryptographic hashing.

2. Zero Data Collection

Connect Tag does not collect, transmit, or store any personal data, hardware identifiers, or usage telemetry from workstations running Soor USB.

For enterprise inquiries, please contact us at: info@connecttag.org.
