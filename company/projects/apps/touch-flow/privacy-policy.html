1. طبيعة المعالجة المحلية (100% Local Execution)

يعمل تطبيق "نَسَق" (TouchFlow) بالكامل داخل بيئة الحاسوب المحلي للمستخدم، ويتواصل مباشرة مع جهاز أندرويد المتصل محلياً عبر جسر تصحيح أخطاء النظام الرسمي. لا يتطلب البرنامج إنشاء حساب سحابي ولا يتصل بأي خوادم خارجية.

2. البيانات التي يعالجها البرنامج محلياً

  • إحداثيات اللمس وخصائص عناصر الشاشة: تُقرأ أبعاد الشاشة وعناصر الواجهة محلياً فقط أثناء جلسة التسجيل أو التنفيذ لتحديد مواقع النقر والبحث الشرطي.
  • ملفات سيناريوهات الماكرو: تُحفظ جلسات العمل وخطوات الأتمتة كملفات محلية على جهاز الحاسوب الخاص بالمستخدم في المسار الذي يحدده بنفسه.

3. أذونات الاتصال المحلي

  • الاتصال المحلي بالجهاز المتصل: يتطلب البرنامج تفعيل خيار تصحيح الأخطاء البرمجية على جهاز أندرويد المتصل وبموافقة صريحة من المستخدم لتنفيذ أوامر اللمس والاختبار الآلي.
  • حفظ واستيراد الملفات محلياً: يستخدم نوافذ النظام القياسية لحفظ واستيراد ملفات سيناريوهات الماكرو.

4. عدم مشاركة البيانات مع أطراف ثالثة

لا تقوم شركة كونكت تاق بجمع أو نقل أي بيانات من الحاسوب أو الهاتف المتصل، ولا يتضمن البرنامج أي أدوات تتبع أو إعلانات.

5. الاحتفاظ بالبيانات وحذفها

تُخزن جميع ملفات الماكرو والسجلات محلياً على جهاز المستخدم فقط، ويمكن للمستخدم حذفها في أي وقت. لمزيد من المعلومات العامة، يرجى زيارة: صفحة إدارة وحذف البيانات.

Executive Summary: Nasaq (TouchFlow), developed by Connect Tag, operates strictly as a local desktop automation studio communicating directly with connected Android devices. The software does not collect, upload, or transmit any user data or macro scripts to external servers.

1. 100% Local Execution

TouchFlow runs entirely on the user's local computer and communicates directly with connected Android devices over the official system debugging bridge. It requires no cloud account and performs no external network requests.

2. Locally Processed Data

  • Touch Coordinates & UI Hierarchy Metadata: Screen dimensions and UI element attributes are inspected locally in real time solely to execute recorded taps, gestures, and conditional checks.
  • Macro Session Files: Automation workflows and step sequences are saved locally on the user's computer in user-selected directories.

3. Local Device Connection

  • Authorized Local Device Bridge: Requires explicit user authorization on the connected Android device to allow local touch recording and automated action execution.
  • Local File Import/Export: Uses standard operating system file dialogs to load and save macro configuration files.

4. Zero Third-Party Data Sharing

Connect Tag collects no telemetry, screen content, or personal data from the host computer or connected mobile devices, and includes no third-party tracking or advertising modules.

5. Data Retention & Deletion

All saved macro sessions and logs reside solely on the user's local storage and can be deleted at any time. For general data management guidance, visit our Data Deletion & Management Page.
