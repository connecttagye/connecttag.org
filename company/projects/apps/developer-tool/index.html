وصف التطبيق

تطبيق "مطور" (Developer) هو الاستوديو الهندسي والحقيبة المتكاملة لمطوري البرمجيات، مهندسي تطبيقات أندرويد، ومبرمجي الويب، تم تطويره بواسطة كونكت تاق (Connect Tag) ليجمع باقة متكاملة تضم 19 أداة تقنية متخصصة في واجهة عصرية وسلسة مبنية بأحدث معايير Jetpack Compose و Material Design 3.

تم تصميم التطبيق وفق معمارية المعالجة المحلية أولاً (Offline-First Architecture) بحيث تتم كافة العمليات البرمجية، التشفير، المعاينة الحية، وتحليل النصوص محلياً داخل ذاكرة جهازك دون اتصال خارجي وبانعدام تام للإعلانات أو أدوات التتبع (Zero Analytics SDKs)، مع حصر استخدام إذن الإنترنت بالاستدعاء اليدوي فقط لاختبار واجهات الـ API وبوتات تيليجرام.

المميزات والخصائص الرئيسية

منسق ومحلل JSON ومولد كود Kotlin

تنسيق (Prettify)، ضغط (Minify)، عرض شجري تفاعلي للمفاتيح والقيم، مع ميزة توليد كود فئات بيانات Kotlin Data Classes تلقائياً بنقرة زر.

مختبر واجهات الـ REST API

إرسال طلبات (GET, POST, PUT, DELETE) مع إدارة الترويسات (Headers)، المعلمات (Params)، المصادقة (Auth Tokens)، وتصدير أوامر cURL للطرفية.

محرر الأكواد ومعاينة الويب الحية

تلوين برمجي ذكي لأكثر من 10 لغات برمجية، التفاف الأسطر، أرقام الأسطر، البحث والاستبدال، مع شاشة معاينة حية لصفحات HTML/CSS.

محلل وفاحص رموز الـ JWT

فك تشفير وفحص ترويسة وحمولة JSON Web Token محلياً، فحص وقت الانتهاء والصلاحية، والتحقق من التوقيع الرقمي HMAC-SHA256.

مشفر ومحول النصوص المتعدد

تشفير وفك تشفير النصوص بخوارزميات متعددة: AES (128/256-bit CBC مع مفتاح سري)، DES، Caesar Cipher، Hex، وشيفرة مورس.

محول SVG إلى Vector و Compose

تحويل ملفات وأكواد رسوميات SVG الفيكتورية مباشرة إلى كود Android Vector Drawable XML وكود Jetpack Compose ImageVector.

مدير ويب هوك وبوتات تيليجرام

التحقق من توكن البوت، فحص حالة الويب هوك والتحديثات المعلقة، ربط وفك الويب هوك، تشخيص شهادة SSL واستجابة السيرفر، وإرسال رسائل فحص.

محرك ومختبر التعابير النمطية (RegEx)

اختبار وتدقيق الأنماط النمطية فورياً مع تمييز لوني للمطابقات، واستخراج مجموعات الأقواس الفرعية (Capturing Groups).

مختبر الروابط العميقة (Deep Links)

اختبار إرسال أوامر Android Intents والروابط المخصصة (Custom Schemes) و App Links للتأكد من فتح الشاشات المستهدفة بالتطبيقات.

ملتقط الألوان ومحول وحدات الشاشة

استخراج أكواد الألوان بنظام HEX و ARGB و Compose Color، مع محول دقيق بين وحدات DP و PX و SP بناءً على كثافة شاشة جهازك.

مولد سياسات الخصوصية وشروط الاستخدام

صياغة سياسات خصوصية وشروط استخدام احترافية تدعم معايير Google Play 2026 ولوائح GDPR و CCPA و COPPA مع التصدير بصيغة HTML و Markdown.

دليل HTTP وأدوات التوقيت والمعرفات

مرجع RFC 9110 لأكواد وترويسات HTTP مع حلول المشكلات، محول Unix Epoch، مولد معرفات UUID v4، ومستخرج بصمات SHA-1 / SHA-256.
