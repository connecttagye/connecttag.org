الوصف

تطبيق "مطور" (Developer) هو الاستوديو الهندسي والحقيبة المتكاملة لمطوري البرمجيات، مهندسي تطبيقات أندرويد، ومبرمجي الويب. يجمع باقة متكاملة تضم 19 أداة تقنية متخصصة لمعالجة وتنسيق النصوص والأكواد، فحص واجهات الـ REST API، تشفير وفك تشفير الرموز، واختبار الألوان والمتجهات محلياً بنسبة 100% بدون إعلانات وبحماية تامة للبيانات.

صُمم تطبيق مطور ليكون الحقيبة البرمجية المحمولة لكل مبرمج ومهندس أنظمة، حيث يجمع أدوات فحص الشبكات وتحليل الحزم واختبار الواجهات البرمجية والتعامل مع الترميزات والبيانات المهيكلة مباشرة من هاتفك بكفاءة عالية وبدون أي اعتماد على خوادم وسيطة.

المزايا والخصائص

  • منسق ومحلل JSON ومولد كود Kotlin: تنسيق وضغط وعرض شجري تفاعلي للبيانات مع توليد كود فئات بيانات Kotlin Data Classes تلقائياً بنقرة زر.
  • مختبر واجهات الـ REST API: إرسال طلبات (GET, POST, PUT, DELETE) مع إدارة الترويسات (Headers) والمعلمات والمصادقة وتصدير أوامر cURL.
  • محرر الأكواد ومعاينة الويب الحية: تلوين برمجي ذكي لأكثر من 10 لغات برمجية مع شاشة معاينة حية لصفحات HTML و CSS و JavaScript.
  • محلل وفاحص رموز الـ JWT: فك تشفير وفحص ترويسة وحمولة JSON Web Token محلياً والتحقق من الصلاحية والتوقيع الرقمي HMAC-SHA256.
  • مشفر ومحول النصوص ودوال التجزئة (Hash): توليد دوال الهاش (MD5, SHA-256) وتشفير AES (128/256-bit) محلياً بدون إرسال البيانات لأي جهة.
  • محول ألوان ورسوم متجهة (Vector): منتقي ألوان متقدم (HEX, RGB, HSL) ومحول متجهات SVG إلى رسومات متجهة برمجية وتنسيقات أندرويد المعيارية.
