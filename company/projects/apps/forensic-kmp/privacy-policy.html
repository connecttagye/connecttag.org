ملخص تنفيذي: صُمم تطبيق "تَقصّي" (Taqassi)، المطور بواسطة شركة كونكت تاق (Connect Tag) (معرف الحزمة: com.connecttag.forensic)، ليعمل في بيئة معزولة تماماً بدون إنترنت (100% Offline). لا يطلب التطبيق إذن الاتصال بالإنترنت ولا يرسل أي بيانات أو سجلات إلى أي خادم خارجي.

1. المعالجة المحلية المعزولة (100% On-Device & Offline)

يعمل تطبيق "تَقصّي" (Taqassi) كاستوديو تحليلي محلي بالكامل على جهاز المستخدم (أندرويد أو سطح المكتب ويندوز). تتم قراءة ملفات الأرشيف وفهرستها وتحليلها داخل قاعدة بيانات محلية آمنة على جهازك ضمن مساحة التخزين المعزولة للتطبيق (App Sandboxed Storage) دون أي اتصال شبكي.

2. البيانات التي يعالجها التطبيق محلياً

  • ملفات الأرشيف المستوردة: يقرأ التطبيق فقط الملفات والمجلدات التي يختارها المستخدم صراحةً عبر منتقي الملفات الرسمي للنظام.
  • الفهارس والملاحظات التحليلية: تُحفظ فهارس البحث، العلامات المرجعية، التصنيفات، وقواعد إخفاء النصوص الحساسة محلياً على جهاز المستخدم فقط.

3. أذونات النظام والوصول للملفات

  • اختيار الملفات والمجلدات (User-Selected File Access): يعتمد التطبيق على منتقي الملفات والمجلدات الرسمي للنظام لفتح أرشيف المحادثات أو حفظ التقارير المصدرة في المسار الذي يحدده المستخدم بنفسه.
  • انعدام الاتصال الشبكي: لا يتضمن التطبيق أي صلاحيات اتصال بالإنترنت أو مزامنة سحابية.

4. عدم مشاركة البيانات مع أطراف ثالثة

لا تقوم شركة كونكت تاق بجمع أو استلام أو الاطلاع على أي ملفات أو محادثات أو تقارير تتم معالجتها داخل التطبيق، ولا يحتوي التطبيق على أي حزم تحليلات أو تتبع.

5. الاحتفاظ بالبيانات وحذفها

يملك المستخدم السيطرة الكاملة على قواعد البيانات المحلية والتقارير المصدرة، ويمكنه حذف أي أرشيف مستورد من داخل التطبيق فوراً أو مسح بيانات التطبيق بالكامل من إعدادات النظام. لمزيد من الإرشادات العامة، يرجى زيارة: صفحة إدارة وحذف البيانات.

Executive Summary: Taqassi, developed by Connect Tag (Package ID: com.connecttag.forensic), is engineered to operate in a 100% offline environment. The application does not request network access and never transmits any archive files, messages, or reports to external servers.

1. 100% On-Device & Offline Processing

Taqassi functions exclusively as a local analytical inspection studio on the user's device (Android or Windows Desktop). All archive parsing, indexing, and linguistic analysis occur within a secure local on-device database inside sandboxed application storage with zero network connectivity.

2. Locally Processed Data

  • Imported Archive Files: The application accesses only the specific files or directories explicitly selected by the user through the system file picker.
  • Search Indexes & Annotations: Search indexes, bookmarks, custom categories, and text redaction rules are stored strictly on the local device.

3. System Access & Security

  • User-Selected File Access: Utilizes the operating system's standard file and folder selection dialogs to read user-selected archives and export generated reports.
  • Zero Network Connectivity: The application operates without internet permissions or cloud synchronization.

4. Zero Third-Party Data Sharing

Connect Tag never collects, receives, or accesses any files, conversations, or analytical reports processed within the application, and embeds no third-party telemetry or tracking libraries.

5. Data Retention & Deletion

Users retain full control over all local databases and exported reports and may delete any imported archive directly within the application or clear application storage via operating system settings. For general guidance, visit our Data Deletion & Management Page.
