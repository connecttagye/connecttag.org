تصف هذه السياسة كيفية تعامل Connect Tag مع البيانات عند استخدام تطبيق مدونة (BlogNote). صُمم هذا التطبيق وفق مبدأ التخزين المحلي الكامل (Offline-First) وانعدام التتبع لحماية خصوصيتك وملاحظاتك الشخصية بنسبة 100%.

1. عدم جمع أو نقل البيانات (Zero Data Collection)

نحن لا نجمع، ولا نخزن، ولا ننقل، ولا نبيع، ولا نشارك أي نوع من بياناتك الشخصية، أو نصوص ملاحظاتك، أو تسجيلاتك الصوتية، أو قوائم مهامك، أو صورك إلى أي خوادم خارجية أو أطراف ثالثة. كافة بياناتك مخزنة محلياً على جهازك فقط.

2. التشفير والحماية المحلية المتقدمة

يستخدم التطبيق معايير حماية وأمان متقدمة:

  • تشفير قاعدة البيانات: يتم تشفير قاعدة بيانات Room محلياً باستخدام محرك SQLCipher بمعيار AES-256.
  • إدارة المفاتيح: تُدار مفاتيح التشفير عبر نظام المفاتيح الآمن لأندرويد (Android Keystore).
  • القفل البيومتري: إمكانية قفل التطبيق ببصمة الإصبع أو الوجه أو قفل الشاشة عبر واجهات androidx.biometric الرسمية.
  • حظر لقطات الشاشة (FLAG_SECURE): منع التقاط الشاشة ومنع ظهور محتوى الملاحظات في قائمة التطبيقات الحديثة.

3. الصلاحيات ونطاق الاستخدام

يلتزم التطبيق بمبدأ الحد الأدنى من الصلاحيات لمتجر Google Play:

  • INTERNET: لجلب بيانات المعاينة الذكية (العنوان والصورة المصغرة) لروابط الويب التي يضيفها المستخدم يدوياً. لا يُستخدم لنقل أي بيانات خاصة.
  • ACCESS_NETWORK_STATE: للتحقق من توفر الاتصال قبل جدولة تنزيل معاينات الروابط لتوفير البطارية.
  • POST_NOTIFICATIONS: لإرسال إشعارات التذكيرات المجدولة التي يحددها المستخدم (Android 13+).
  • SCHEDULE_EXACT_ALARM: لجدولة منبهات التذكيرات بدقة عبر AlarmManager.
  • RECEIVE_BOOT_COMPLETED: لاستعادة التذكيرات النشطة تلقائياً بعد إعادة تشغيل الهاتف.
  • USE_BIOMETRIC: لتمكين القفل البيومتري بالبصمة.
  • VIBRATE: لتقديم اهتزازات لمسية تفاعلية أثناء الاستخدام.
  • WAKE_LOCK: للحفاظ على المعالجة المؤقتة لمهام WorkManager الخلفية.

4. التخزين ونظام Scoped Storage

لا يطلب التطبيق أي صلاحيات تخزين واسعة مثل MANAGE_EXTERNAL_STORAGE أو READ_EXTERNAL_STORAGE. تُحفظ كافة الملفات والمرفقات في النطاق الآمن والمعزول الخاص بالتطبيق (context.filesDir).

5. النسخ الاحتياطي المشفر بكلمة مرور

يتيح التطبيق تصدير نسخة احتياطية مشفرة بكلمة مرور مخصصة تختارها أنت، وتبقى النسخة محفوظة على جهازك ولا يمكن لأي طرف فك تشفيرها دون كلمة المرور الصحيحة.

6. الحسابات والإعلانات والتحليلات

لا يتطلب التطبيق إنشاء حساب مستخدم، ولا يحتوي على أي إعلانات تجارية أو أدوات تتبع سلوكي أو تحليلات إعلانية.

7. اتصل بنا

إذا كان لديك أي أسئلة أو استفسارات بخصوص سياسة الخصوصية، يسعدنا تواصلك معنا عبر البريد الإلكتروني: support-apps@connecttag.org.

App: BlogNote (مدونة) · Google Play Edition · Effective Date: September 2026

This policy describes how Connect Tag handles data when using the BlogNote app. The application is built on a strict offline-first architecture with zero tracking to ensure 100% privacy for your notes and recordings.

1. Zero Data Collection & Transmission

We do not collect, transmit, sell, log, or share any personal data, notes, audio recordings, checklists, or photos with any remote servers or third parties. Everything remains strictly stored on your local device.

2. On-Device Security & Encryption

BlogNote implements robust security layers:

  • Database Encryption: Powered by SQLCipher with AES-256 database encryption.
  • Key Management: Hardware-backed encryption key protection via Android Keystore.
  • Biometric Lock: App locking via Fingerprint, Face ID, or PIN via androidx.biometric.
  • Anti-Screenshot Mode (FLAG_SECURE): Optional protection against unauthorized screen captures and app-switcher snooping.

3. App Permissions & Functional Justification

BlogNote adheres strictly to the Principle of Least Privilege:

  • INTERNET: Fetches OpenGraph preview metadata for manually pasted web links. Never used for user tracking.
  • ACCESS_NETWORK_STATE: Checks connectivity before scheduling link preview tasks to conserve battery.
  • POST_NOTIFICATIONS: Delivers scheduled reminders and alerts (Android 13+).
  • SCHEDULE_EXACT_ALARM: Schedules precision reminder alarms using AlarmManager.
  • RECEIVE_BOOT_COMPLETED: Re-schedules active alarms after device reboots.
  • USE_BIOMETRIC: Enables biometric unlock.
  • VIBRATE: Provides tactile feedback.
  • WAKE_LOCK: Ensures reliable background execution of WorkManager tasks.

4. Scoped Storage Compliance

BlogNote does not request broad storage permissions (MANAGE_EXTERNAL_STORAGE / READ_EXTERNAL_STORAGE). All attachments are stored in the app's isolated private sandbox (context.filesDir).

5. Password-Encrypted Backups

BlogNote allows exporting password-encrypted backup files. Decryption without the correct password is mathematically impossible.

6. No Accounts, Ads, or Analytics

BlogNote does not require user accounts and contains zero ads or third-party behavioral analytics SDKs.

7. Contact Us

If you have any questions or feedback regarding this Privacy Policy, please contact us at: support-apps@connecttag.org.
