تطبيق: سَبْر (Sabr: APK Security & Inspection Studio) · تاريخ السريان: أكتوبر 2026

توضح هذه السياسة كيفية تعامل شركة كونكت تاق لتقنية المعلومات (Connect Tag) مع بياناتك وملفاتك عند استخدامك لبرنامج "سَبْر" (Sabr) المخصص للتدقيق والفحص الأمني لحزم وتطبيقات أندرويد. نحن نلتزم بحماية خصوصيتك الرقمية وضمان سرية كافة حزم التطبيقات وشفراتها المصدرية ونتائج تدقيقها تحت سيطرتك الحصرية.

1. المعالجة المحلية الكاملة دون اتصال (100% On-Device Processing)

صُمم تطبيق "سَبْر" كأداة تدقيق وفحص أمني تعمل محلياً بالكامل على حاسوبك الشخصي:

  • تتم جميع عمليات فك حزم التطبيقات، وتحليل الشهادات الرقمية، واستخراج النصوص، ومسح الثغرات والمفاتيح الحساسة، محلياً على معالج جهازك دون الحاجة للاتصال بالإنترنت.
  • لا يتم رفع، أو نسخ، أو إرسال أي ملفات حزم تطبيقات (APK) أو شفرات برمجية أو تقارير فحص إلى أي خوادم خارجية تابعة لكونكت تاق أو لأي طرف ثالث.

2. الصلاحيات والتعامل مع الملفات

يلتزم برنامج "سَبْر" بمبدأ الامتياز الأدنى (Least Privilege) وتقليل الوصول للملفات إلى ما يحدده المستخدم بنفسه فقط:

  • فتح حزم التطبيقات: يختار المستخدم الحزم والملفات المراد فحصها عبر منتقي الملفات الرسمي للنظام دون طلب صلاحيات وصول واسعة لملفات القرص.
  • حفظ وتصدير التقارير: تُحفظ تقارير الفحص الأمنية الناتجة (بصيغ HTML أو Markdown أو JSON) حصرياً في المسار والمجلد الذي يحدده المستخدم بإرادته.
  • الاتصال بالأجهزة المحمولة (اختياري): عند تفعيل خيار فحص الأجهزة المتصلة، يتم التواصل محلياً ومباشراً عبر كابل التوصيل السلكي بين حاسوبك والهاتف، ولا تمر أي معلومات عبر الإنترنت إطلاقاً.
  • حفظ التفضيلات وقواعد الفحص: تُحفظ الإعدادات والتفضيلات محلياً داخل مساحة التخزين الخاصة والمعزولة للتطبيق على جهازك.

3. عدم جمع البيانات الشخصية أو التتبع

نحن لا نجمع، ولا نخزن، ولا نبيع، ولا نشارك أي معلومات شخصية، أو معرفات أجهزة، أو بصمات تطبيقات. التطبيق خالٍ تماماً من أي أدوات تتبع، أو إعلانات، أو تحليلات سلوكية للجهة المطورة.

4. التواصل والاستفسارات

لأي استفسارات قانونية أو فنية تتعلق بسياسة الخصوصية الخاصة بتطبيق سَبْر، يرجى التواصل معنا عبر: support-apps@connecttag.org أو info@connecttag.org.

App: Sabr (APK Security & Inspection Studio) · Effective Date: October 2026

This Privacy Policy outlines how Connect Tag respects and safeguards your digital privacy when using the Sabr Android APK security auditing and inspection studio. Engineered as a standalone desktop utility, Sabr guarantees that all inspected application packages, binary signatures, decompiled sources, and security findings remain strictly confidential and under your direct physical custody.

1. 100% On-Device Sandboxed Local Processing

Sabr operates on a strict offline-first paradigm with complete data isolation:

  • Package parsing, digital certificate validation, bytecode decompilation, secrets detection, and vulnerability assessments run entirely within your local system's memory and CPU.
  • No application binaries, decompiled classes, secrets findings, or audit reports are ever uploaded, transmitted, or synchronized with external servers or third-party networks.

2. File Access & Device Connectivity

Sabr strictly adheres to the principle of least privilege:

  • Package Selection: Target application packages (APK files) are loaded exclusively via the native operating system file picker based on direct user action.
  • Audit Exporting: Comprehensive security reports (HTML, Markdown, or JSON) are written solely to directories explicitly selected by the user.
  • Local Device Bridge (Optional): Direct physical USB communication with test devices occurs locally on your machine without external relay or remote intermediation.
  • Local Preferences: User settings, analysis filters, and interface states are retained strictly within secure local on-device sandboxed storage.

3. No Personal Data Collection or Trackers

We do not collect, monetize, log, or transmit any user identity markers, hardware fingerprints, network identifiers, or telemetry. Sabr is completely free of third-party advertising SDKs, behavioral tracking frameworks, or analytics beacons.

4. Contact Information

If you have any questions or feedback regarding this Privacy Policy, please contact our compliance and security team at: support-apps@connecttag.org or info@connecttag.org.
