بيانات الهوية التقنية

  • الشركة المصنعة
  • الموديل والمواصفات
  • رقم الـ TAC المعتمد
  • حالة الفحص مطابق للمواصفات الرسمية

كيف تجد الأرقام المطلوبة؟

  • للهواتف: اطلب الكود *#06# وسيظهر لك رقم IMEI فوراً.
  • للمودمات: ستجد الرقم مطبوعاً على الملصق خلف الجهاز أو أسفل البطارية.
  • TAC: هو اختصار لـ Type Allocation Code ويمثل أول 8 أرقام من الـ IMEI.

عن كونكت تاق

شركة يمنية رائدة في تقديم الحلول البرمجية والأنظمة المحاسبية والتسويق الرقمي بأعلى معايير الجودة والاحترافية.
