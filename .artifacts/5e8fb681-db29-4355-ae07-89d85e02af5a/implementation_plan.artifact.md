# خطة تحسين بنية الأدوات وتعزيز SEO (Best Practices)

تعتمد هذه الخطة على تحويل مجلد الأدوات من مجرد "قائمة روابط" إلى "مركز معرفي تقني" منظم، مما يعزز ظهور الموقع في نتائج البحث المتخصصة.

## أهم الممارسات المقترحة (SEO Best Practices)

1.  **هيكلية الروابط (Siloing):** تنظيم المحتوى في مجموعات مترابطة (Clusters) بحيث ترتبط الأدوات بصفحة الفئة الأم، والصفحة الأم ترتبط بالقسم الرئيسي.
2.  **المحتوى الغني (Thin Content Avoidance):** إضافة نصوص شرحية (300+ كلمة) في صفحات الفئات تشرح فوائد الأدوات وكيفية استخدامها، بدلاً من عرض الأيقونات فقط.
3.  **بيانات منظمة (Schema Markup):** إضافة `ItemList` Schema لصفحات الفئات لتعريف محركات البحث بالخدمات المتاحة.
4.  **تجربة المستخدم (UX):** استخدام Breadcrumbs واضحة وتصميم متسق مع الهوية البصرية.

## المكونات المقترحة للتطوير

### 1. صفحات الفئات (Category Landing Pages)
إنشاء ملف `index.html` في كل من:
- `tools/telecom/` (أدوات الاتصالات)
- `tools/web/` (أدوات المطورين)
- `tools/mobile/` (أدوات تطبيقات الجوال)
- `tools/security/` (الأمن والخصوصية)

### 2. تحسين صفحة الأدوات الرئيسية (`tools/index.html`)
- تعديل الروابط لتشير إلى صفحات الفئات أولاً، أو عرض "أهم الأدوات" مع زر "عرض الكل في هذه الفئة".

## مقترح التغييرات التفصيلي

### [Component] الهيكل الفني لكل صفحة فئة

#### [NEW] `tools/[category]/index.html`
كل صفحة ستتبع القالب التالي:
- **SEO Meta:** عنوان فريد يركز على الفئة (مثلاً: "أفضل أدوات فحص المودمات في اليمن").
- **Introduction:** نص تسويقي وتقني حول الفئة.
- **Tool Grid:** عرض الأدوات التابعة للفئة فقط.
- **FAQ Section:** أسئلة شائعة حول هذه الأدوات (لرفع ترتيب SEO).

## خطة التنفيذ (Tasks)

### المرحلة الأولى: التجهيز
- [ ] إعداد نصوص SEO (العناوين والأوصاف) لكل فئة.
- [ ] اختيار الكلمات المفتاحية الأكثر بحثاً لكل قسم.

### المرحلة الثانية: البرمجة
- [ ] إنشاء قالب (Template) موحد لصفحات الفئات بناءً على تصميم الموقع الحالي.
- [ ] توزيع الأدوات على صفحاتها الجديدة.
- [ ] إضافة Schema Markup (JSON-LD) لكل صفحة.

### المرحلة الثالثة: الربط والأرشفة
- [ ] تحديث `tools/index.html` ليعكس الهيكلية الجديدة.
- [ ] تحديث `sitemap.xml`.

---

## خطة التحقق (Verification Plan)

### الاختبارات التلقائية
- استخدام أداة `Site Checker` الخاصة بك لفحص الـ SEO الداخلي لكل صفحة جديدة.
- التأكد من استجابة الصفحات (Responsive Design).

### التحقق اليدوي
- مراجعة الروابط الداخلية (Internal Links) للتأكد من عدم وجود روابط مكسورة.
- فحص سرعة التحميل (LCP) للتأكد من عدم تأثر الأداء بإضافة المحتوى النصي.
